# Global Style — Celestial Cat Tarot

## Direction

Celestial Astrology + Cosmic Vintage Tarot + Fine Art Illustration.

## Master palette

| Name | Hex |
|------|-----|
| Cosmic black | `#080910` |
| Midnight blue | `#111A38` |
| Indigo | `#343A75` |
| Nebula violet | `#68528E` |
| Star gold | `#D9B66F` |
| Aged paper cream | `#E7D7B5` |

Per-card secondary palettes are allowed; stay within the same family (deep space, gold accents, controlled violet/indigo).

## Visual rules

- Deep cosmic backgrounds: small stars, restrained nebula, orbital lines, constellations, zodiac motifs, planets.
- Antique gold tarot border feel; illustration occupies most of the frame.
- Purposeful lighting on the cat; hand-painted texture; spatial depth.
- Avoid: plastic 3D, generic anime, clipart, harsh neon, excessive bloom, messy collage.

## Generation format

- **Art-only**: no text, numbers, or titles in the generated image.
- Target aspect for generation: **3:4**; final deliverable **2:3** via compositor (`templates/card_frame.svg`).
