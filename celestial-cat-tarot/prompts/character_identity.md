# Character Identity — Celestial Cat

## Reference files

| File | Purpose |
|------|---------|
| `assets/reference/cat_reference.png` | Primary identity (cosmic portrait) |
| `assets/reference/cat_reference_face.png` | Face / eyes / M marking (if present) |
| `assets/reference/cat_reference_belly.png` | Belly spots / underside pattern (if present) |

Always pass `cat_reference.png` in `reference_image_paths` for generation. Add face or belly ref when the pose shows those areas.

## Non-negotiable traits

- Domestic shorthair, lean natural proportions (not chibi, not humanoid).
- Brown-grey tabby with warm black/brown stripes and spots.
- Lighter warm tan/golden muzzle, chin, and belly patches.
- Round yellow-green (golden-hazel) eyes.
- Large triangular ears, brown-pink nose, natural whiskers.
- Long tail with dark rings and darker tip.

## Allowed variation

- Pose, gaze, expression, motion, props, subtle costume elements per card meaning.

## Forbidden

- Different breed, solid color coat, wrong eye color, missing/changed tabby pattern, oversized cartoon head, anthropomorphic body, extra limbs, cropped ears/tail.

## Identity block (paste into every image prompt)

```
Same specific cat: domestic shorthair tabby, brown-grey and warm black tabby stripes and spots, lighter golden-tan muzzle and belly, round yellow-green eyes, large ears, pink-brown nose, long ringed tail with dark tip, natural feline anatomy and proportions, recognizable as the reference cat.
```
